适用环境：Windows / VS Code / PowerShell

使用方法
--------
1. 在 VS Code 中打开项目，选择“终端 → 新建终端”，终端使用 PowerShell。
2. 按需要分段复制下面 powershell 标记之间的命令，不复制标记本身。
3. 本文件是说明清单，不是批处理脚本，不要一次执行全文。
4. 每一步成功后再做下一步；出错时先处理错误。
5. 标注“无 API 调用”的命令不使用 DeepSeek 额度；训练仍会占用本机计算资源。
6. API Key 在自己的终端输入，不需要发送到聊天，也不要写进配置文件。
7. 推荐顺序：A → B → C → D。E 为可选的较大规模实验。

B. 小样本端到端测试（无 API 调用）
==================================

B1. 准备小样本数据

```powershell
.venv\Scripts\python.exe -m agentsa --config configs/smoke.yaml prepare
```

效果：从真实数据抽样并做小样本过滤；保存固定划分与目标列表。
输出：data\processed\smoke\
当前配置得到 94 用户、128 商品、327 条交互。
注意：这份样本使用 2-core，仅用于检查代码，不是正式全量 5-core 实验。
重复执行会核对已有数据后复用，不修改原始压缩包。

B2. 生成模拟 Agent 的假评分

```powershell
.venv\Scripts\python.exe -m agentsa --config configs/smoke.yaml generate-agent --mock
```

效果：使用确定性模拟接口，检查画像、选品、评分、记忆和保存流程。
输出：runs\smoke_agent_checked\mock\target_27\fake_ratings.csv
目标 ID 来自 B1 保存的目标列表；当前配置为 27。
注意：这不是 DeepSeek 生成的数据，不能用来证明真实 AgentSA 的效果。

B3. 只测试 NMF 和两种传统攻击，快速查看训练流程

```powershell
.venv\Scripts\python.exe -m agentsa --config configs/smoke.yaml run --models nmf --methods random,average --seeds 11
```

效果：在小样本上训练干净 NMF、Random/Average 投毒 NMF，再比较指标。
输出：runs\smoke_checked\experiments\results.csv
说明：这里使用真实样本及传统攻击，没有模拟或真实 LLM 参与。
仅运行 4 个 epochs 是管线测试配置，不能据此评价模型或攻击优劣。

B4. 检查两种模型与全部攻击配置

```powershell
.venv\Scripts\python.exe -m agentsa --config configs/smoke.yaml run --include-agent --match-agent-budget --mock-agent
```

效果：两种模型各比较六种传统攻击、仅目标评分、模拟 Agent，共 16 个组合。
--include-agent：加入已保存的 Agent 假评分，不会现场调用模型。
--match-agent-budget：传统攻击沿用 Agent 的每用户 filler 数量。
--mock-agent：读取模拟 Agent 数据，并把输出隔离在 mock_validation 目录。
输出：runs\smoke_checked\mock_validation\results.csv 和 summary.json。
重复执行会复用匹配的模型 checkpoint，并重新评测。

B5. 在终端查看结果


D3. 创建独立的小规模 DeepSeek 配置（只写配置，不发请求）

```powershell
  fake_ratio: 0.0002
agent:
  output: runs/agent_data_deepseek_pilot

  output: runs/phase1_deepseek_pilot
```

效果：创建 configs\deepseek_pilot.yaml，不修改原来的 deepseek.yaml。

F. 日常查看、恢复与常见问题
==========================

F1. 用 VS Code 打开项目

```powershell
code C:\Projects\AgentSA
```

效果：打开项目。解释器选 .venv\Scripts\python.exe。

F2. 查看固定目标和数据清单

```powershell
Get-Content .\data\processed\full\targets.json
Get-Content .\data\processed\full\manifest.json
```

效果：核对目标列表、划分数量、数据哈希与预处理设置。

F3. 查看上一条程序是否成功

```powershell
$LASTEXITCODE
```

效果：外部程序正常退出通常是 0；非 0 表示错误，应先阅读报错。
在你想检查的 Python 命令结束后立即执行。

F4. 中断和恢复

按 Ctrl+C 中断当前运行。
Agent 生成：修复问题后执行原 generate-agent 命令，复用缓存与已保存的轮次状态。
模型训练：已完成且配置匹配的模型可复用；尚未完成的单个模型会从头训练。
如果是异常关闭留下 .generation.lock，先确认旧进程已经结束，再处理锁文件；不要并发写同一输出目录。

F5. 常见报错

- No module named ...：先确认使用 .venv\Scripts\python.exe；语义依赖缺失则执行 D1。
- Set DEEPSEEK_API_KEY：在当前终端重新执行 C1。
- HTTP 401/403：检查 Key、账户权限与服务地址；doctor=true 只代表变量存在。
- HTTP 402：检查服务账户余额或额度；以服务方具体说明为准。
- HTTP 429：可能遇到限流，程序有界重试；稍后在原配置下续跑。
- Model output was truncated：输出被截断，可减少一次请求的内容或增加 max_tokens；改变配置后用新 Agent 输出目录。
- Existing checkpoint uses different settings：模型/配置/代码变了，换新的 experiment.output，避免覆盖旧实验。
- Agent settings/model changed：换新的 agent.output，不要混用不同模型生成的历史。
- Budget limit reached：先看 usage.json，再决定是否增加限额；不需要重新生成已完成的数据。
- 真实 Agent 报 lexical encoder is for --mock：误用了 smoke.yaml；真实调用使用 deepseek.yaml 或 deepseek_pilot.yaml。

F6. 结果解释

clean_hr / poison_hr：攻击前后目标进入 Top-10 的真实用户比例。
delta_hr：poison_hr - clean_hr，正值表示目标曝光增加。
signed_prediction_shift：目标预测评分的平均有符号变化。
absolute_prediction_shift：目标评分变化的平均绝对值。
delta_rmse / delta_mae：真实测试评分预测误差的变化。
fake_ratings：该次注入评分总条数，用于核对预算。
仅目标评分对照故意只有目标交互，不要求与其他方法 filler 数量一致。

每次 run 的 results.csv 和 summary.json 汇总“本次命令”的范围，可能覆盖上次汇总。
逐模型/目标/方法/种子的训练与指标文件仍分别保存在 poison 目录。
想长期保留不同命令的汇总，请用不同 experiment.output，或另存结果 CSV。

--------

模拟数据、小样本测试、低注入比例 pilot 均不等同于正式论文效果复现。
本轮只创建指令文件，没有替你执行付费 API 命令或启动正式实验。
