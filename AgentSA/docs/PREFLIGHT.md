# 正式实验前：干净模型检查与 pilot 排名诊断

该工具仅在本地训练、读取已有 checkpoint 和评分，不导入或调用 LLM 客户端。

在项目根目录执行：

```powershell
Set-Location C:\Projects\AgentSA
$env:PYTHONIOENCODING = 'utf-8'
.venv\Scripts\python.exe -m agentsa.preflight --stage all
.venv\Scripts\python.exe -m agentsa.preflight_report
```

默认结果目录为 `runs/preflight_20261102/`，阅读其中的 `REPORT.md`。

## 干净模型检查

- 数据划分与全量 pilot 一致。
- NMF 学习率为 0.001、0.0003；NeuNMF 为 0.001、0.0003、0.0001。
- 每组使用训练种子 11、22、33；最多 100 轮，早停耐心值 10。
- 模型结构、正则、优化器和批量大小保持原设置。
- 以三个种子的最佳验证 RMSE 均值选取学习率；测试与攻击效果不参与选择。
- 15 个训练配置保存各自模型、完整验证曲线、配置和代码哈希。
- 这是有限网格检查，不是完整超参数搜索或显著性检验。

选中的配置位于 `selected_configs/nmf.yaml`、`selected_configs/neunmf.yaml`。
它们保留 3 人 pilot 的攻击规模，主要用于复用已经选定的训练设置；不能直接称为正式 5% 攻击配置。
两个模型可以使用各自学习率，但同一模型的 clean/所有 poison 必须使用相同训练设置。

## 原 pilot 排名诊断

读取 `configs/deepseek_pilot.yaml` 对应的 `experiments/results.csv`，定位干净/投毒模型。
载入 checkpoint 前核对数据身份、模型源代码、训练源代码和配置指纹，不会在旧目录训练或写文件。

全物品排序与原评估相同：只评估训练中未对目标评分的真实用户，屏蔽训练已见商品，同分按递增商品 ID 排序。

新增输出：

- 排名均值以及 P10/P25/P50/P75/P90。
- HR@10、HR@50、HR@100；HR@10 继续作为主要曝光指标。
- 目标评分与 Top-10/50/100 门槛的分差。
- 每个用户投毒前后的排名改善；改善、不变、恶化用户比例。
- 逐用户 CSV、压缩数组和排名累积分布图。

门槛分差定义为“目标预测评分减去第 K 名可推荐商品的预测评分”，候选包含目标。
负数表示低于门槛；零可能是并列，最终命中由包含 ID 平局规则的排名判断。
排名改善定义为“干净排名减去投毒排名”，正值表示改善。

诊断重新计算的 HR@10、有符号 Prediction Shift 必须与原 pilot 一致，否则终止并报告错误。
诊断使用旧 pilot 模型；选出的新学习率不会被回写到旧模型或伪装成新参数下的攻击结果。

## 可复现与复用

可用 `--stage tune` 或 `--stage diagnose` 单独运行一个步骤。
`--config` 和 `--output` 可指定配置与独立输出路径；汇总工具也可指定 `--output`。

原 pilot/Agent 文件在运行前后核对哈希，完成清单记录核对结果。
重复运行可复用指纹一致的模型与排名缓存。修改规则、源代码、训练设置时使用新的输出目录。
不要同时启动多个写入相同目录的进程。

本步骤不生成 992 人攻击数据，不启动 5% 正式实验。
